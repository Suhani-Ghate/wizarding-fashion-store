# Nocturne — Harry Potter-Inspired Fashion Website ✨

Nocturne is a fashion website inspired by the Harry Potter universe. It combines fashion with the magical atmosphere of the wizarding world through themed collections and visual design.

Live Website: https://nocturne.free.nf/

About the Project:
Nocturne is a WordPress-based fashion website created around a Harry Potter-inspired theme. The project focuses on presenting fashion collections through a design that reflects the magic and mystery of the wizarding world.
The website is frontend-only, focusing on the visual design, layout, navigation, and presentation of content. It does not include backend functionality or database-driven data storage.

Built With:
- WordPress
- WordPress Site Editor

Features:
- Harry Potter-inspired fashion aesthetic
- Themed collections inspired by the wizarding world
- An elegant, magic-inspired visual design
